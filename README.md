MasterScanner — антимайнер и поведенческая защита для Windows

MasterScanner — это ультралёгкая портативная утилита (всего ~48 КБ) для обнаружения скрытых криптомайнеров, зачистки точек их автозапуска и поведенческой защиты системы в реальном времени. Программа не требует установки, не тормозит компьютер, потребляет минимум оперативной памяти и работает даже с обычной USB-флешки.

Основные возможности


1. Глубокий поиск угроз («Запустить проверку»)

• Анализ командной строки процессов. Сканирует аргументы запуска всех активных процессов и находит скрытые майнеры, использующие популярные протоколы и алгоритмы (stratum+tcp, xmrig, randomx, rx/0, kawpow, ethash, nicehash, 2miners, kryptex и др.).
• Поиск двойников системных процессов. Выявляет вредоносные файлы, замаскированные под стандартные службы Windows (svchost.exe, winlogon.exe, csrss.exe, taskhostw.exe), если они запущены не из системной папки C:\Windows.
• Контроль неподписанных исполняемых файлов. Проверяет наличие цифровой подписи у процессов, запущенных из типичных «вирусных» директорий (AppData, Temp, ProgramData, Users\Public).
• Проверка файла hosts. Находит посторонние перенаправления, которыми вирусы блокируют доступ к сайтам антивирусов и обновлениям системы.

2. Комплексное удаление «с корнем» («Обезвредить выбранное»)

Одним нажатием утилита выполняет полный цикл лечения:
1. Принудительно завершает вредоносный процесс.
2. Перемещает исполняемый файл в изолированную папку Quarantine (с изменением расширения на .quarantine, чтобы исключить случайный запуск).
3. Удаляет связанные задачи из Планировщика задач Windows (schtasks).
4. Вычищает записи автозапуска из веток реестра Run и RunOnce (для текущего пользователя и всей системы).

3. Три щита защиты в реальном времени

Включаются и отключаются независимо друг от друга в верхнем меню «Защита в реальном времени»:
• Монитор майнеров (CPU / GPU / RAM / Сеть). Каждые 5 секунд замеряет нагрузку на процессор, видеокарту и оперативную память. Если неподписанная программа грузит CPU или GPU более чем на 40% (либо занимает от 1.5 ГБ RAM) или устанавливает соединение с известными портами майнинг-пулов (3333, 4444, 14444 и др.) — программа мгновенно поднимает тревогу.
• Щит от шифровальщиков (Honeypot-ловушки). Создаёт скрытые системные папки-приманки на дисках и отслеживает скорость изменения пользовательских файлов. При попытке изменения файлов-ловушек или массовой модификации документов (от 15 файлов за 2 секунды) щит немедленно останавливает все неподписанные процессы и выводит окно экстренного выключения ПК для спасения данных.
• Контроль USB-флешек и папки «Загрузки». Отслеживает появление и запуск опасных скриптов (.vbs, .ps1, .hta) и неподписанных программ во временных папках и на съёмных носителях, отправляя угрозы в карантин до заражения системы.

4. Глубокая ревизия системы

• Очистка исключений Защитника Windows. Многие современные майнеры через PowerShell добавляют свои папки (AppData, Temp, ProgramData) в белый список Windows Defender. Утилита проверяет список исключений и удаляет подозрительные пути.
• Аудит Планировщика задач. Ищет скрытые задачи, запускающие скрипты (powershell, mshta, wscript, cmd) из временных папок.

5. Облачное обновление баз и фоновый режим

• Актуальные сигнатуры без переустановки. Пункт меню «Файл → Обновить базы угроз» загружает свежий список сигнатур майнеров и сетевых портов пулов из облачного репозитория и сохраняет его в локальный файл signatures.db.
• Тихая работа в трее. Поддерживается автозапуск вместе с Windows в свёрнутом виде (--silent). При нажатии на крестик программа не закрывается, а сворачивается в значок щита в области уведомлений рядом с часами.

Пошаговая инструкция по использованию

1. Подготовка папки. Поместите MasterScanner.exe в отдельную папку на диске (например, C:\MasterScanner\), а не прямо на Рабочий стол — рядом с файлом программа будет автоматически создавать папку Quarantine и файл баз signatures.db.
2. Запуск с правами Администратора. Нажмите на MasterScanner.exe правой кнопкой мыши и выберите «Запуск от имени администратора». Без прав администратора Windows заблокирует завершение системных двойников, чистку Планировщика задач и удаление исключений Defender.
3. Обновление баз. Перед первой проверкой откройте «Файл → Обновить базы угроз», чтобы подгрузить актуальные правила.
4. Проверка и лечение. Отметьте нужные пункты в меню «Глубокая очистка» и нажмите «Запустить проверку». Выделите найденную угрозу в таблице и нажмите «Обезвредить выбранное».
5. Настройка постоянной защиты. Включите нужные щиты в меню «Защита в реальном времени» и поставьте галочку «Файл → Запускать вместе с Windows (в трей)». Выбранные настройки сохраняются в реестре автоматически.

Важные технические нюансы (прочитайте перед запуском)

• Реакция Windows SmartScreen. Утилита является независимой разработкой и не подписана дорогим коммерческим сертификатом EV Code Signing. При первом запуске Windows покажет стандартное синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».
• Ложные срабатывания эвристики (VirusTotal / антивирусы). Поскольку MasterScanner напрямую сканирует память других процессов, завершает задачи, редактирует системный реестр и использует PowerShell для очистки исключений Defender, некоторые эвристические антивирусы (например, Microsoft ML, GData, Gridinsoft, Huorong) могут помечать файл как PUP, CoinMiner (из-за поиска сигнатур майнеров) или Wacatac!ml. Это стандартная особенность любых утилит системной диагностики и лечения (аналогично AVZ или Process Hacker). Для стабильной работы добавьте папку C:\MasterScanner\ в исключения вашего антивируса.
• Системные требования. Windows 10 / Windows 11 (x64 / x86), предустановленный в системе .NET Framework 4.8 (входит в состав современных версий Windows по умолчанию).
